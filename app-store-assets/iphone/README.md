# iPhone App Store screenshots

The five final screenshots are rendered at Apple's 6.7-inch portrait size of
1320 × 2868 pixels. They use the same generated midnight-aurora source as the
Apple Watch campaign and deterministic SVG overlays so all product copy remains
legible and accurate.

Run `./generate-iphone-screenshots.sh` after installing `librsvg` and
ImageMagick. Data shown in the marketing compositions is explicitly identified
as illustrative sample data.
